# THRIVE: Track, Habits, Responsibility, Invest, Value, Earn

Free money lessons for kids and parents. Short lessons, videos, and quizzes on saving, budgeting, credit, and investing.

## Run it locally

```bash
npm install
npm run dev     # http://localhost:8080
npm run build   # production build in dist/
```

Tech notes for contributors are in `AGENTS.md`.
